# AI品牌案例筛选册

六例已核验的公开 AI 品牌案例，IP、品牌、形象各两例。页面只收录公开事实、日期、AI 证据、原始来源、置信与局限，以及你在当前浏览器里做的个人挑选。

挑选状态写在本机 `localStorage`，不上传、不同步，也不发布。导出的 CSV / JSON 只供你自己在设备之间转移；导入只按案例编号写回状态。

图片是公开报道或官方频道的轻量封面和配图，并注明出处。完整影片只链接到原始页面，仓库里不存放成片。

## 本地打开

在本目录启动静态服务器后打开首页。直接用 `file://` 打开时，浏览器可能拦截 `evidence.json`。

```bash
python3 -m http.server 8765
```
